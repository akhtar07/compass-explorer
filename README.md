# COMPASS Explorer

Interactive one-stop explorer for the COMPASS binary-alloy phase-classification
framework: 970 binary systems with ground-truth phase labels (isomorphous /
partial / immiscible / intermetallic), orbital / Hume-Rothery descriptors, and
multi-source DFT properties (Materials Project, OQMD, JARVIS).

Live: https://akhtar07.github.io/compass-explorer/

## Descriptors
- **COMPASS-9** = D1–D8 + D13. D1–D8 are orbital / Hume-Rothery descriptors from
  Harrison tight-binding theory and free-atom data; D13 is the periodic-group
  distance |G_A − G_B|. No DFT input.
- **D9–D12** are optional DFT/LOBSTER bonding descriptors (|ICOHP|, ICOBI),
  present only for systems whose elements have LOBSTER data.

## Tabs
- **Search** — instant one-stop search (element, pair, phase behaviour, property
  need, formula), phase facets, pin-and-compare.
- **Periodic Table** — click-to-classify (element → its 970-set partners → full
  system page) and property heatmap over the elements.
- **Classification Map** — scatter of any two descriptors, coloured by
  ground-truth class or DFT-stable compound count.
- **Ashby Chart** — element constants or binary systems positioned by extracted
  DFT properties.
- **Descriptors** — definitions of D1–D13.
- **Benchmark** — the paper's descriptor ladder (Hume-Rothery rule, e/a,
  Miedema, COMPASS-9, MAGPIE, +DFT-hull) with per-class F1 and 95 % CIs, a
  learner × feature-set matrix (XGBoost, nested Optuna, classifier chains,
  MLP, EBM, TabPFN), leave-one-family-out, conformal coverage, y-scramble null
  and the label-noise screen. Every number is read from
  `public/data/benchmark.json`.
- **Upload** — view your own phase-diagram image (client-side).

Each system page shows the ground-truth label(s), the out-of-fold MAGPIE
prediction with per-class probability, the D1–D13 radar, a "Why this
classification" panel (decision-tree rules + TreeSHAP over COMPASS-9) and the
source-tagged DFT properties.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # -> dist/
npm run preview    # serve the production build
```

## Deploy
GitHub Actions (`.github/workflows/deploy.yml`) builds and publishes `dist/`
to GitHub Pages on every push to `main`. `base: './'` keeps all paths relative.
(`netlify.toml` is kept only for reference.)

## Data (`public/data/`)
- `pairs.json` — 970 pairs: D1–D13 (D9–D12 where available), ground-truth
  labels, out-of-fold MAGPIE predictions and probabilities, property ranges,
  phase-diagram filename.
- `benchmark.json` — model results; generated by `build_benchmark.py` from the
  paper's `data/processed/ml/adv/adv_summary.json`.
- `interpretability.json` — per-class rules and SHAP drivers.
- `dft_by_system.json` — multi-source DFT properties per binary system.
- `elements.json`, `element_properties.csv`, `property_*.json`,
  `prop_labels.json` — element property layer.

## Regeneration scripts (repo root)
- `build_benchmark.py [adv_summary.json]` — rebuilds `benchmark.json`.
- `sync_truth_labels.py [phase_labels_970.csv]` — syncs each pair's ground-truth
  label list with the canonical 970-pair label table.
- `add_d13_to_pairs.py`, `add_element_names.py`, `build_property_layer.py` —
  earlier data-layer builders.
